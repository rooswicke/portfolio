## Projecten

### 1. Smaakvol: app om recepten te beheren

**Type:** Fullstack webapplicatie · Examenopdracht Front-end & Back-end Web Development  
**Status:** Afgerond · Live · Team van 2

Met Smaakvol bewaar en beheer je je recepten. Gebruikers maken een account aan, voegen recepten toe met ingrediënten en foto's, en admins beheren de volledige inhoud. Het project bestaat uit een React-frontend en een NestJS-API, allebei gedeployed op Render.

**Technologieën**

| Laag | Stack |
|------|-------|
| Frontend | React, Vite, Tailwind CSS |
| Backend | NestJS, Drizzle ORM |
| Database | MySQL |
| Testing | Cypress (e2e), Jest |
| Extra | Multer, Swagger, Docker |
| Deployment | Render |

**Highlights**
- REST API met volledige CRUD voor recepten, ingrediënten en gebruikers
- Authenticatie met JWT en rollen (admin / gebruiker)
- Foto's uploaden met Multer
- End-to-end tests met Cypress
- Automatisch gegenereerde API-documentatie met Swagger
- Docker-setup voor lokale ontwikkeling

**Links**
- [Live app](https://smaakvol.onrender.com)
- [Live API](https://frontendweb-2526-plaswicke.onrender.com)
- [Repository](https://github.com/HOGENT-frontendweb/frontendweb-2526-PlasWicke)

### 2. Delaware Admin App: platform voor bedrijfsadministratie

**Type:** Enterprise-teamproject · Projecten II, in opdracht van Delaware  
**Status:** Afgerond · Teamproject

Een administratieplatform voor Delaware, een Belgisch IT-consultancybedrijf. In team bouwden we drie applicaties die samenwerken: een webfrontend, een REST API en een aparte Java-desktopapplicatie. Het project liep met een echte klant en volgde een realistische werkwijze.

**Technologieën**

| Onderdeel | Stack |
|-----------|-------|
| Frontend | React |
| Backend | REST API |
| Desktop | Java |

**Highlights**
- Opdracht van een echte klant, met bijhorende vereisten en opvolging
- Drie aparte applicaties die met elkaar samenwerken
- Samenwerken in een groter team met Git en GitHub
